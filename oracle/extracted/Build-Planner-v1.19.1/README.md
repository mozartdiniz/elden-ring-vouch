## How to read this extract

- `csv/` holds a snapshot of cell **values** (cached results when available; stored values otherwise). On large data-only workbooks, formula cells are written as formula text because a second cached-value pass was skipped.
- `formulas/` holds the **logic**. Prefer the PATTERN section: identical fill-down formulas are compressed to a template with `{r}` for the row.
- `kind=spill_cache` is **not** logic. It is a spilled Google Sheets array result.
- `kind=google_sheets` is the recovered original Sheets formula (FILTER, QUERY, …).
- Dropdowns/inputs are listed under DATA VALIDATION.
