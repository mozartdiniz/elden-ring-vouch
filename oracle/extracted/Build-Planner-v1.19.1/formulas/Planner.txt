COMMENTS (author notes on UI / semantics):
  E6: If you don't care about the changes listed in Changelog you can:
    
    Go to the UpdateData page and edit cell D2 to equal the update version
    
    Doing so will remove the notification until the next update
    
    If this says TRUE or is highlighted green with no update you can run the fix_updateBooleanFormat macro to restore proper functionality
  E7: See Changelog for details
    
    If this is giving an error you can run the fix_importRangeError macro to restore proper functionality
  AM8: This will delete the selected build
    
    Does not clear selections so you have a chance to recover a deleted build if you change your mind
  E10: You may need to "Load Build" twice depending on Talisman and Spell usage relative to previously loaded slots.
    
    If you use the "Load Build" button you can ignore the following:
    
    All selections need to be cleared for a build to load without the script buttons.
  E11: Name used for saving build
    
    If this name matches a saved build it will edit that build instead of saving a new one
  AQ14: None of the damage multipliers are reflected in the AP display because they are not AP multipliers.
    
    Almost every effect that increases damage is a damage multiplier.
  V15: Toggles between attack values and guard values
  AC15: GB = Guard Boost
  AC17: Sorcery/Incant Scaling
  AI33: +10% Fire Damage Negation
    -10% Lightning Damage Negation
  AI34: +10% Fire Damage Negation
    -10% Lightning Damage Negation
  AI35: Toggles attack power penalties for lacking requirements
  AE36: Has priority over Low HP
  AI36: Toggles Scaling display between letters and values
  AI37: Display all starting classes under "Optimal Classes" so you can see how many levels are saved/lost between them
  AI38: Hides default builds from the dropdown menu; they will always be sorted at the bottom of the list if visible
  E42: Valid input is 2-10
  E45: Uses highest Sorcery/Incant Scaling equipped by default
    
    If two or more slots have equal Sorcery/Incant Scaling it will prioritize RH1>RH2>RH3>LH1>LH2>LH3 with no manual selection
  T47: Intelligence | Faith | Arcane
  E61: There will be no valid spell/catalyst if the selected catalyst cannot cast any of the selected spells
